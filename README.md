Udemy Clone Website 🎓

A simple Udemy clone web page built using HTML and CSS.
This project replicates the basic layout and design of the Udemy platform, focusing on a clean UI and structured course display.

🚀 Features

Home page with course listings

Header with navigation bar

Course cards with title, instructor, rating, and price

Category section

Footer section

Clean and minimal UI design

🛠️ Technologies Used

HTML5

CSS3

📸 Preview

🎯 Purpose

Practice HTML & CSS layout design

Improve front-end development skills

Understand real-world website structure

📌 Note

This project is not responsive and is intended for desktop view only.
